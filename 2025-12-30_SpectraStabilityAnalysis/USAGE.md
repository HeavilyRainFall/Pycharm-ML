# 光源光谱稳定性分析工具

## 项目概述

此项目用于分析手电筒光源的光谱稳定性。通过比较不同时间点的光谱数据与初始参考数据（0分钟）的差异，评估光源系统的稳定性。

## 功能特性

1. 加载所有光谱数据文件
2. 光谱曲线对比图
3. 强度差异分析
4. 统计稳定性指标
5. 交互式网页报告
6. 整体稳定性趋势分析

## 文件结构

- `spectra_analysis.py`: 主要分析代码
- `app.py`: Streamlit应用入口
- `requirements.txt`: 项目依赖
- `README.md`: 项目说明

## 使用说明

1. 确保已安装所有依赖：`pip install -r requirements.txt`
2. 运行应用：`streamlit run app.py`
3. 在浏览器中打开 http://localhost:8501 查看分析结果

## 分析内容

1. 光谱强度对比图
2. 相对差异分析
3. 稳定性指标（平均差异、最大差异、相关系数等）
4. 稳定性随时间变化的趋势图

## 数据格式

- 第一列为波长信息（nm）
- 第二列为强度信息
- 文件命名格式：`手电筒光源光谱数据 - {时间}.csv`
- 以时间后缀为0的文件作为参考组
- 其他文件作为测量组
