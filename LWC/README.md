# 光谱数据小波变换分析工具

这是一个基于Python的光谱数据分析工具，实现了小波变换去噪和信噪比分析功能，具有友好的图形用户界面。

## 功能特点

- **小波变换去噪**: 使用DB4小波实现光谱数据去噪
- **信噪比分析**: 计算并比较去噪前后的信噪比
- **多数据支持**: 支持单列或多列计数数据同时分析
- **智能文件识别**: 自动识别CSV文件是否有表头
- **图形化界面**: 直观的tkinter GUI界面
- **结果可视化**: 实时显示原始数据、去噪后数据和对比图

## 使用方法

### 1. 启动程序
```bash
python spectral_analyzer_gui.py
```

### 2. 安装额外依赖（支持Excel文件）
```bash
pip install openpyxl xlrd
```

### 3. 生成示例数据（可选）
```bash
python generate_sample_data.py
```

这将生成两个示例文件：
- `sample_spectral_data.csv`: 带表头的多列数据
- `sample_no_header.csv`: 无表头的单列数据

### 3. 界面操作说明

#### 主要功能按钮：
- **导入CSV数据**: 选择并加载光谱数据文件
- **执行小波变换**: 对数据进行小波变换处理
- **计算信噪比**: 计算并显示信噪比分析结果
- **显示原始数据**: 在图表中显示原始光谱数据
- **显示变换结果**: 显示小波去噪后的数据
- **对比显示**: 同时显示原始和去噪后的数据进行对比
- **保存结果**: 将分析结果保存到文本文件
- **清除所有**: 清除当前所有数据和显示

#### 参数设置：
- **小波类型**: 目前支持DB4小波（默认）
- **分解层数**: 小波分解的层数（默认6层）

## 核心算法

### 小波变换实现
基于移植的C语言wavemin库，实现了：
- DB4小波基函数
- 多层离散小波变换(DWT)
- 对称延拓边界处理
- 软阈值去噪算法

### 信噪比计算
使用以下公式计算信噪比：
```
SNR = 10 × log10(信号功率 / 噪声功率)
```
其中：
- 信号功率：信号与其均值的方差
- 噪声功率：相邻点差分的方差

## 注意事项

1. **内存使用**: 处理大数据集时请注意内存使用情况
2. **文件编码**: 程序会自动尝试多种编码格式(utf-8, gbk, gb2312, latin-1)
3. **数据质量**: 建议输入数据具有合理的数值范围，避免极端异常值
4. **分解层数**: 过高的分解层数可能导致过度平滑

## 故障排除

### 常见问题

1. **无法启动程序**
   - 检查Python版本是否符合要求
   - 确认所有依赖包已正确安装

2. **数据加载失败**
   - 检查CSV文件格式是否正确
   - 确认文件编码是否支持
   - 验证数据列数是否足够

3. **计算结果异常**
   - 检查输入数据是否包含有效数值
   - 确认数据范围是否合理
   - 调整小波分解参数
