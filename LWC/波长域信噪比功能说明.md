# 波长域信噪比分析功能使用说明

## 功能概述

新增的"波长域信噪比"功能可以计算并显示每个波长点的局部信噪比分布，帮助您分析光谱仪在不同波长下的噪声特性。

## 功能特点

### 1. 本地信噪比计算
- 基于多帧数据的空间变异性计算每个波长点的信噪比
- 反映光谱仪在特定波长下的实际噪声水平
- 不同于传统的帧间信噪比，提供波长维度的噪声分析

### 2. 可视化展示
- **信噪比谱图**：显示每个波长点的信噪比值变化趋势
- **分布直方图**：展示信噪比值的统计分布情况
- **关键统计信息**：平均值、最大值、最小值等

### 3. 数据要求
- 需要至少两个数据系列（多帧测量数据）
- 数据应包含相同波长范围的不同测量结果
- 适用于评估光谱仪的空间稳定性

## 使用方法

### 1. 数据准备
确保您的数据文件包含多帧测量结果：
```
Wavelength(nm),Frame1,Frame2,Frame3,...
400.0,100.5,98.2,102.1,...
401.0,102.3,99.8,103.5,...
...
```

### 2. 操作步骤
1. 启动光谱分析程序
2. 点击"导入CSV数据"加载包含多帧数据的文件
3. 设置小波变换参数（可选）
4. 点击"波长域信噪比"按钮
5. 查看生成的信噪比图表和统计结果

### 3. 结果解读

#### 信噪比谱图
- **横轴**：波长值（nm）
- **纵轴**：信噪比（dB）
- **趋势线**：显示信噪比随波长的变化情况
- **峰值区域**：信噪比较高的波长段
- **谷值区域**：信噪比较低的波长段

#### 分布直方图
- 显示各信噪比值的出现频率
- 帮助识别信噪比的集中趋势
- 发现异常值分布

#### 统计信息
- **平均信噪比**：整体噪声水平的代表值
- **最大/最小信噪比**：最佳和最差波长点的表现
- **对应波长**：性能最好和最差的具体波长位置

## 技术原理

### 计算方法
1. 对每帧数据进行小波去噪处理
2. 计算去噪后数据的方差（信号功率）
3. 计算原始与去噪数据差值的方差（噪声功率）
4. 按公式 SNR = 10×log10(信号功率/噪声功率) 计算每个波长点的信噪比

### 算法优势
- **局部敏感性**：能发现特定波长段的噪声问题
- **空间分析**：基于多帧数据的空间变异性评估
- **实用性强**：直接反映实际测量条件下的性能

## 应用场景

### 1. 设备性能评估
- 评估光谱仪在不同波长下的稳定性
- 识别设备的薄弱波长段
- 比较不同设备的波长响应特性

### 2. 质量控制
- 监测设备性能变化趋势
- 发现潜在的硬件问题
- 验证校准效果

### 3. 实验设计优化
- 选择信噪比较高的波长段进行测量
- 避免噪声敏感区域
- 优化实验参数设置

## 注意事项

1. **数据质量**：确保输入数据质量良好，避免异常值影响结果
2. **帧数要求**：建议使用5-10帧数据以获得稳定的统计结果
3. **波长范围**：确保所有帧数据覆盖相同的波长范围
4. **结果解释**：结合物理意义合理解释信噪比分布特征

## 故障排除

### 常见问题

**问题1：提示"需要至少两个数据系列"**
- 原因：加载的数据只有一列计数数据
- 解决：确保数据文件包含多列计数数据

**问题2：信噪比值为负数**
- 原因：正常现象，在噪声较大的波长段会出现
- 解决：关注相对变化趋势而非绝对数值

**问题3：图表显示异常**
- 原因：可能缺少matplotlib库或显示驱动问题
- 解决：确保正确安装matplotlib库
