# 光谱数据小波变换分析工具 - 更新说明

## 新增功能

### 1. 文件夹批量加载功能
现在支持一次性加载整个文件夹中的所有光谱数据文件，包括：
- **支持格式**：CSV、Excel (.xlsx/.xls)
- **自动识别**：程序会自动扫描文件夹中的所有支持格式文件
- **批量处理**：将多个文件的数据合并为多个数据系列进行分析
- **灵活操作**：保留原有的单文件加载功能

**使用方法**：
1. 点击"导入文件夹"按钮
2. 选择包含光谱数据文件的文件夹
3. 程序自动加载所有支持的文件
4. 每个文件作为一个独立的数据系列进行处理

### 2. 信噪比显示格式统一为比值
根据用户要求，所有信噪比显示均已改为比值形式：
- **去除dB单位**：不再使用分贝表示
- **统一格式**：所有SNR值均以纯数值比值显示
- **清晰易懂**：直接显示信号与噪声的功率比值

**显示变更**：
- 原来：SNR = 20.5 dB
- 现在：SNR = 4.23（比值）

## 功能说明

### 文件加载选项
- **导入单个文件**：传统方式，选择单个CSV或Excel文件
- **导入文件夹**：批量加载文件夹内所有数据文件
- **数据合并**：自动将多个文件组织为独立的数据系列

### 信噪比分析
- **整体信噪比**：计算每个数据系列的整体信噪比
- **波长域信噪比**：计算每个波长点的局部信噪比分布
- **比值显示**：所有结果均以信号/噪声功率比值形式呈现

### 小波变换
- 支持DB4小波基
- 可调节分解层数（1-10层）
- 自动阈值去噪处理

## 使用建议

### 数据准备
1. **单文件模式**：适合单一实验或测试数据
2. **文件夹模式**：适合批量实验、时间序列或多条件对比

### 结果解读
- **信噪比比值**：数值越大表示信号质量越好
- **波长分布**：可识别特定波长段的噪声特性
- **改善倍数**：去噪前后信噪比的比值变化

## 技术细节

### 文件夹加载机制
- 自动识别支持的文件格式
- 假设所有文件具有相同的波长轴
- 每个文件的第二列作为计数数据
- 自动处理文件读取错误，跳过无效文件

### 信噪比计算
- **整体SNR**：基于帧间变异性的传统计算方法
- **局部SNR**：基于空间变异性的波长域分析
- **统一输出**：全部以线性比值形式返回

## 注意事项

1. 文件夹加载时建议文件命名规范，便于识别
2. 确保所有文件具有相同的波长范围和采样点数
3. 信噪比比值形式更适合直接比较和数学运算
4. 如需dB表示，可用公式：dB = 10×log10(比值)自行转换
