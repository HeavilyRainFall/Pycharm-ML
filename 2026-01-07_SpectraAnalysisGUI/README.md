# 光谱数据分析GUI程序

这是一个用于分析光谱数据的GUI应用程序，能够计算信噪比(SNR)、动态范围和分辨率，并生成包含图表和统计信息的HTML报告。

## 功能特性

1. **SNR和动态范围分析**：
   - 计算每个波长的信噪比：SNR = (S-D)/std
   - 计算动态范围：DR = (65535-D)/std，其中D为连续9帧数据的平均值
   - 显示统计信息（最大值、最小值、均值、中位数）

2. **分辨率分析**：
   - 对每个文件进行寻峰
   - 计算每个峰的半高全宽(FWHM)
   - 显示统计信息（最大值、最小值、均值、中位数）

3. **可视化**：
   - 在GUI界面中实时显示图表
   - 生成包含图表和统计信息的HTML报告

4. **用户友好**：
   - 默认读取程序所在文件夹的对应子文件夹
   - 如果默认路径不存在则提示用户选择
   - 支持中文界面

## 安装和运行

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 准备数据

在程序所在目录下创建以下文件夹结构：
- `SNR/D/` - 存放暗噪声数据文件（CSV格式）
- `SNR/S/` - 存放信号数据文件（CSV格式）
- `分辨率/` - 存放分辨率分析数据文件（CSV格式）

### 3. 运行程序

```bash
python spectra_analysis.py
```

## 使用方法

1. **分析SNR和动态范围**：
   - 点击"分析SNR和动态范围"按钮
   - 程序会自动查找`SNR`文件夹，如不存在则提示选择
   - 分析完成后在界面中显示图表和统计信息

2. **分析分辨率**：
   - 点击"分析分辨率"按钮
   - 程序会自动查找`分辨率`文件夹，如不存在则提示选择
   - 分析完成后在界面中显示图表和统计信息

3. **生成报告**：
   - 点击"生成报告"按钮
   - 选择保存位置和文件名
   - 生成包含所有图表和统计信息的HTML报告
   - 可选择立即打开报告

## 数据格式要求

- CSV文件，第一列为波长，第二列为测量值
- 文件可以有或没有表头
- SNR分析需要D和S两个子文件夹，每个包含相同数量的文件
- 分辨率分析的文件夹包含需要分析的光谱数据文件
