# 光谱数据分析程序项目信息

## 项目概述

光谱数据分析程序是一个用于分析光谱数据的GUI应用程序，能够计算信噪比(SNR)、动态范围和分辨率，并生成包含图表和统计信息的HTML报告。

## 项目结构

```
├── 光谱数据分析程序（信噪比、动态范围、分辨率）.exe  # 打包后的可执行文件
├── spectra_analysis.py        # 主程序源代码
├── requirements.txt           # 依赖库列表
├── build_exe.py             # 标准打包脚本

├── PROJECT_INFO.md          # 本文件

│   ├── D/                  # 暗噪声数据

```

## 功能特性

### 1. SNR和动态范围分析
- 计算每个波长的信噪比：SNR = (S-D)/std
- 计算动态范围：DR = (65535-D)/std
- 显示统计信息（最大值、最小值、均值、中位数）
- 实时图表显示

### 2. 分辨率分析
- 对每个文件进行寻峰
- 计算每个峰的半高全宽(FWHM)
- 显示统计信息（最大值、最小值、均值、中位数）
- 实时图表显示

### 3. 报告生成
- 生成包含图表和统计信息的HTML报告
- 支持浏览器查看
- 包含完整的分析结果

### 4. GUI界面
- 直观的图形用户界面
- 支持中文显示
- 交互式图表展示
- 简单易用的操作流程

## 技术栈

- **Python**: 核心编程语言
- **Tkinter**: GUI界面框架
- **Matplotlib**: 数据可视化
- **Pandas**: 数据处理
- **NumPy**: 数值计算
- **SciPy**: 信号处理
- **PyInstaller**: 应用程序打包

## 数据格式

### CSV文件格式
- 第一列为波长值
- 第二列为测量值
- 可以有或没有表头
- 支持多行数据

### 文件夹结构
- `SNR/D/`: 暗噪声数据文件
- `SNR/S/`: 信号数据文件
- `分辨率/`: 分辨率分析数据文件

## 统计信息

### SNR统计
- 最大值、最小值、平均值、中位数

### 动态范围统计
- 最大值、最小值、平均值、中位数

### 分辨率统计
- FWHM（半高全宽）的最大值、最小值、平均值、中位数
