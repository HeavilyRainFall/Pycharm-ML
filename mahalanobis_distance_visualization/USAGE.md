# 使用说明：马氏距离与高斯函数关系可视化应用

## 启动应用

1. 打开终端或命令提示符
2. 导航到项目目录：
   ```bash
   cd D:\pycharm jupyter git\mahalanobis_distance_visualization
   ```
3. 安装依赖（如果尚未安装）：
   ```bash
   pip install -r requirements.txt
   ```
4. 启动Streamlit应用：
   ```bash
   streamlit run app.py
   ```

## 应用界面说明

### 主界面
- 顶部显示应用标题和简要介绍
- 中间部分显示可视化图形
- 底部包含马氏距离概念解释和计算示例

### 侧边栏参数控制
- **分布类型**：选择"椭圆分布"或"高斯分布"视图
- **均值 x/y**：设置二维分布的均值点坐标
- **协方差参数**：
  - σxx：X方向方差
  - σyy：Y方向方差
  - σxy：XY协方差（控制椭圆旋转角度）

### 马氏距离计算区域
- 输入目标点坐标
- 查看计算出的马氏距离值
- 在图形中可视化连接均值点和目标点的线段

## 交互操作指南

1. **调整分布形状**：
   - 改变均值参数移动椭圆中心
   - 调整协方差参数改变椭圆的形状和方向

2. **切换可视化模式**：
   - 椭圆分布模式：显示等高线和椭圆轮廓
   - 高斯分布模式：显示3D概率密度的2D投影

3. **计算特定点的马氏距离**：
   - 在底部输入框中输入坐标
   - 查看计算结果和可视化连线

## 教学要点

通过调整参数，您可以观察到：
- 协方差矩阵如何决定椭圆的形状和方向
- 马氏距离考虑了数据分布的形状，不同于欧氏距离
- 等马氏距离的点形成椭圆形状
- 高斯分布的等概率密度线为椭圆
