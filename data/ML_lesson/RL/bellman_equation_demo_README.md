# 贝尔曼方程迭代演示程序

这个GUI程序用于演示强化学习中贝尔曼方程的迭代过程，帮助理解动态规划在强化学习中的应用。

## 程序功能

1. **可视化网格世界**：4x4的网格世界，包含状态价值和奖励矩阵
2. **参数调节**：可以调节折扣因子、收敛阈值和最大迭代次数
3. **迭代控制**：支持单步迭代和自动迭代直到收敛
4. **数学公式展示**：显示贝尔曼方程的数学表达式和推导过程

## 贝尔曼方程简介

贝尔曼方程是动态规划的核心，描述了状态价值函数之间的关系：

- **贝尔曼期望方程**：
  V(s) = R(s) + γ × Σ p(s'|s,a) × π(a|s) × V(s')

- **贝尔曼最优方程**：
  V*(s) = R(s) + γ × max_a Σ p(s'|s,a) × V*(s')

## 算法说明

程序实现了值迭代算法：
- V(k+1)(s) = R(s) + γ × max_a Σ p(s'|s,a) × V(k)(s')

算法从任意初始价值函数开始，通过迭代更新直到收敛到最优价值函数。

## 网格世界设置

- 4x4网格世界，共16个状态
- 终止状态：右上角(0,3)，奖励为+1.0
- 障碍状态：(1,1)，奖励为-1.0
- 其他状态奖励为0
- 动作：上、右、下、左四个方向

## 使用方法

1. 运行程序：`python bellman_equation_demo.py`
2. 调节参数（折扣因子、收敛阈值等）
3. 点击"Start Iteration"自动迭代或"Step Iteration"单步迭代
4. 点击"Visualization"查看数学过程说明
5. 点击"Reset"重置程序

## 程序界面

- 左侧：控制面板，包含参数调节和按钮
- 右上：状态价值函数热力图
- 右下：奖励矩阵热力图
- 底部：贝尔曼方程数学公式
